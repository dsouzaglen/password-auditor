Privacy by design

Useful findings without exposing secrets

The audit runs entirely on the local machine and returns derived findings only.

01

Password assessment

Scores estimated entropy, length, character variety, common passwords, dates, repeated characters, and predictable sequences.

02

Authentication monitoring

Uses sliding time windows to identify single-account guessing, multi-account bursts, and distributed attacks.

03

SOC-ready output

Writes newline-delimited JSON with rule IDs, severity, MITRE mappings, affected entities, and recommended actions.

Detection engineering

Three explainable alert patterns

Each default is documented and tunable for the environment being monitored.

RulePatternDefault thresholdMITRE ATT&CK
PA1001One source → one account5 failures / 60 secT1110.001
PA1002One source → many accounts10 accounts / 60 secT1110
PA1003Many sources → one account10 sources / 60 secT1110.001

Analyst note: Multi-account failures are labeled as a heuristic. Authentication metadata alone cannot reliably distinguish password spraying from credential stuffing.
